   KEY INSIGHT
   ===========

   The smooth_data function is fundamentally designed for SMALL datasets.

   Test case (qcalc_test.py line 100-101):
     self.x, self.y = meshgrid(arange(100), arange(100))
     self.I = (...)  # shape (100, 100) = 10,000 points

   This works fine! 10,000 points × 8 bytes × ~7 arrays = ~560 MB peak

   But actual data:
     OffSpecular combined from multiple datasets = 35,000,000+ points

   Scaling: 35M / 10K = 3,500× larger
   Memory: 560 MB × 3,500 ≈ 2 TB peak (impossible!)

   Even with garbage collection, allocator fragmentation wins after
   500-1000 iterations of massive reallocation cycles.
