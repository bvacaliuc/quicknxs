   EXECUTIVE SUMMARY
   The smooth_data function has severe memory inefficiencies that compound with data size,
   causing OOM kills (exit 137). The primary issue is that for each grid point iteration,
   LARGE temporary arrays are created without proper memory management.

      CRITICAL LOOP (lines 270-293):
      For each grid point (i, j) in output grid (imax × len(Xout[0])):

      Line 285 or 287: **MAIN MEMORY PROBLEM**
      rij = (x-xij)**2/ssigmaxi + (y-yij)**2/ssigmayi
      OR
      rij = (x-xij)**2/ssigmax + (y-yij)**2/ssigmay

      WHAT HAPPENS:
      - (x - xij) creates a NEW TEMPORARY ARRAY of size len(x)
      - (x - xij)**2 creates ANOTHER NEW TEMPORARY ARRAY
      - (y - yij)**2 creates ANOTHER NEW TEMPORARY ARRAY
      - Division operations create MORE TEMPORARY ARRAYS
      - Final addition creates ANOTHER array
      - Result: rij is a LARGE array with shape = (N_points,) where N_points = len(x)

      MEMORY PER GRID POINT:
      - If x,y,I have 50,000,000 elements (conservative estimate for combined datasets)
      - Each float64: 8 bytes
      - rij alone: 50M × 8 bytes = 400 MB
      - Plus temporary arrays during computation: 5-10× the size = 2-4 GB per grid point

      TOTAL GRID POINTS: gridx × gridy (e.g., 100 × 100 = 10,000 grid points)

      If this loop processes ALL 10,000 points sequentially:
      - Theoretical: 10,000 points × 400 MB = 4 TB (IMPOSSIBLE!)
      - In practice: Python garbage collects old arrays, but memory fragmentation occurs
      - Peak memory: Several GB per iteration

      Line 288: take = where(rij < sigmas**2)
      - where() returns a tuple of indices
      - Creates ANOTHER array of indices (typically small if sigma filtering works)

      Line 291: Pij = exp(-0.5*rij[take])
      - Creates NEW array of size len(take[0])
      - Then normalized and multiplied

      Line 293: Iout[i, j] = (Pij * I[take]).sum()
      - Another temporary array from multiplication

         - Loop runs 10,000 times (for 100×100 grid)
         - Each iteration creates rij of size = input data points (15M-60M)

      d) NO EARLY TERMINATION:
